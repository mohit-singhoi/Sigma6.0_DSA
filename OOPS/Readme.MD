# 📖 Overview

Object-Oriented Programming (OOP) is a programming paradigm that organizes software around **objects** rather than functions. Java is a fully object-oriented language that provides powerful features to build modular, reusable, scalable, and maintainable applications.

This folder contains Java implementations demonstrating all core OOP principles along with numerous examples and practice programs.
