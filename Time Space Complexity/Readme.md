---

# 📖 Overview

Time Complexity is one of the most fundamental concepts in Data Structures and Algorithms. It measures how the execution time of an algorithm grows as the input size increases.

This folder contains Java implementations of mathematical computations, searching algorithms, and sorting algorithms, along with their time complexity analysis. These programs help build intuition for choosing efficient algorithms and understanding algorithm performance.
