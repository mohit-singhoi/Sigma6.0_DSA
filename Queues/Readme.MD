# 📖 Overview

A **Queue** is a linear data structure that follows the **FIFO (First In, First Out)** principle, where the first element inserted is the first one to be removed. Queues are widely used in scheduling, buffering, task processing, graph traversal, and operating systems.

This folder contains Java implementations of various queue types, queue operations, deque implementations, and classic interview problems based on queues.
