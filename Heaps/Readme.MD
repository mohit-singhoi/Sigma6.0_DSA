# 📖 Overview

A **Heap** is a complete binary tree that satisfies the heap property, making it an efficient data structure for implementing **Priority Queues**. Heaps are widely used in scheduling, graph algorithms, sorting, and optimization problems.

This folder contains Java implementations of heap operations, heap sort, Java's `PriorityQueue`, and several classic interview problems that utilize heaps for efficient solutions.
