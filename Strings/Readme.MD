# 📖 Overview

A **String** is a sequence of characters used to represent text in Java. String manipulation is one of the most common tasks in software development and coding interviews. Java provides powerful classes such as **String**, **StringBuilder**, and **StringBuffer** to efficiently process and manipulate text.

This folder contains Java implementations of string operations, string algorithms, mutable string classes, and classic interview problems.
