# 📖 Overview

Recursion is a programming technique where a function calls itself to solve a problem by breaking it down into smaller subproblems. It is one of the most important concepts in Data Structures and Algorithms and forms the foundation for advanced topics such as trees, graphs, divide and conquer, dynamic programming, and backtracking.

This folder contains Java implementations of beginner to intermediate recursion problems, helping build strong recursive thinking and problem-solving skills.
