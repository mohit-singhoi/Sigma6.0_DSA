# ⭐ Pattern Printing

> A comprehensive collection of **Pattern Printing** programs in **Java** covering star patterns, number patterns, character patterns, hollow patterns, pyramids, diamonds, and advanced pattern-based problems. This folder is part of the **Sigma 6.0 – Data Structures & Algorithms with Java** course by **Apna College**.

---

# 📖 Overview

Pattern Printing is one of the best ways to strengthen programming logic and master nested loops. It helps build a solid understanding of iteration, conditional statements, and problem-solving techniques that are essential for Data Structures and Algorithms.

This folder contains Java implementations of various beginner to intermediate pattern printing problems organized into multiple levels for progressive learning.

| Pattern Type | Complexity |
|--------------|------------|
| Square Pattern | **O(n²)** |
| Rectangle Pattern | **O(n²)** |
| Half Pyramid | **O(n²)** |

| Diamond Pattern | **O(n²)** |
| Pascal Triangle | **O(n²)** |
