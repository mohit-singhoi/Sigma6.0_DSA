# 📦 Arrays

> A complete collection of **Array** implementations and interview-oriented problems in **Java**, developed while completing the **Sigma 6.0 – Data Structures & Algorithms with Java** course by **Apna College**.

# 📖 Overview

Arrays are one of the most fundamental data structures in programming. This folder covers everything from array creation and traversal to advanced interview problems using optimized techniques such as Prefix Sum, Kadane's Algorithm, Binary Search, and Matrix operations.

The implementations are divided into **1D Arrays** and **2D Arrays** with separate practice questions for better understanding.
