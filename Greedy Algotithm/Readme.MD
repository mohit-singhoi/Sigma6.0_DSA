# 📖 Overview

Greedy Algorithms are a fundamental algorithmic paradigm used to solve optimization problems by making the **locally optimal choice at each step**, with the hope of reaching a globally optimal solution.

This folder contains Java implementations of classic greedy problems that are frequently asked in coding interviews, competitive programming contests, and technical assessments.
