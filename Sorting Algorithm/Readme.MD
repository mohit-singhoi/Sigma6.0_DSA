# 📖 Overview

Sorting is one of the most fundamental topics in Data Structures and Algorithms. It is used to arrange data in a specific order, making searching, processing, and analysis more efficient. Understanding sorting algorithms is essential for solving coding interview questions and building efficient software applications.

This folder contains Java implementations of basic sorting algorithms, divide and conquer techniques, and Java's built-in sorting methods.

# 📈 Time Complexities

| Algorithm | Best | Average | Worst | Space |
|-----------|------|----------|--------|-------|
| Bubble Sort | **O(n)** | **O(n²)** | **O(n²)** | **O(1)** |
| Selection Sort | **O(n²)** | **O(n²)** | **O(n²)** | **O(1)** |
| Insertion Sort | **O(n)** | **O(n²)** | **O(n²)** | **O(1)** |
| Counting Sort | **O(n + k)** | **O(n + k)** | **O(n + k)** | **O(k)** |
| Merge Sort | **O(n log n)** | **O(n log n)** | **O(n log n)** | **O(n)** |
| Quick Sort | **O(n log n)** | **O(n log n)** | **O(n²)** | **O(log n)** |
