# 📖 Overview

A **Linked List** is a linear data structure where elements are connected using pointers instead of contiguous memory locations. It provides efficient insertion and deletion operations, making it an essential data structure for implementing stacks, queues, hash tables, and many other advanced data structures.

This folder contains Java implementations of fundamental and advanced linked list operations commonly asked in coding interviews and competitive programming.
