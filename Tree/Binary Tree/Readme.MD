# 📖 Overview

A Binary Tree is a hierarchical data structure in which each node has at most two children: the left child and the right child.

Binary Trees form the foundation for many advanced data structures including Binary Search Trees, AVL Trees, Heaps, Segment Trees, and Expression Trees.

This folder contains implementations of traversal algorithms, tree properties, recursive problems, Lowest Common Ancestor (LCA), subtree detection, tree transformation, and many important interview questions.
