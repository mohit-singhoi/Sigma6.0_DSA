# 📊 Segment Tree

> A collection of **Java Segment Tree implementations** covering tree construction, range queries, update operations, maximum/minimum queries, and efficient interval processing.

---

# 📖 Overview

A Segment Tree is an advanced tree-based data structure used to efficiently answer **range queries** and perform **point updates** on an array.

Unlike brute-force approaches, Segment Trees process range queries in **O(log n)** time, making them ideal for competitive programming and large datasets.
