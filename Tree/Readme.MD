# 📖 Overview

Trees are one of the most important non-linear data structures in Computer Science. They are widely used in databases, operating systems, compilers, file systems, search engines, networking, and competitive programming.

This folder contains Java implementations of Binary Trees, Binary Search Trees (BST), Self-Balancing Trees, and Segment Trees, along with many interview-oriented algorithms and problem-solving techniques.

# 📈 Time Complexity

## Binary Tree

| Operation | Complexity |
|-----------|------------|
| DFS Traversals | O(n) |
| Level Order Traversal | O(n) |
| Height | O(n) |
| Count Nodes | O(n) |
| Sum Nodes | O(n) |
| Diameter (Naive) | O(n²) |
| Diameter (Optimized) | O(n) |
| LCA | O(n) |
| Top View | O(n) |
| Subtree | O(n × m) |

---

## Binary Search Tree

| Operation | Average | Worst |
|-----------|---------|--------|
| Search | O(log n) | O(n) |
| Insert | O(log n) | O(n) |
| Delete | O(log n) | O(n) |
| Validate BST | O(n) | O(n) |
| Print Range | O(n) | O(n) |
| Root-to-Leaf Path | O(n) | O(n) |

---

## AVL Tree

| Operation | Complexity |
|-----------|------------|
| Search | O(log n) |
| Insert | O(log n) |
| Delete | O(log n) |

---

## Segment Tree

| Operation | Complexity |
|-----------|------------|
| Build Tree | O(n) |
| Range Query | O(log n) |

| Space | O(4n) |
