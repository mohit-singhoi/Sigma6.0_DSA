# 📖 Overview

Bit Manipulation is one of the most efficient techniques in programming for performing mathematical and logical operations directly on binary representations of integers. It is widely used in competitive programming, system programming, embedded systems, cryptography, and coding interviews.

This folder contains Java implementations of fundamental bitwise operations along with interview-oriented problems and optimization techniques.
