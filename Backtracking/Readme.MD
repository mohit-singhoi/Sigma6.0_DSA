# 📖 Overview

Backtracking is an algorithmic technique that incrementally builds a solution and abandons a path as soon as it determines that the path cannot lead to a valid solution. It is widely used to solve combinatorial optimization and constraint satisfaction problems.

This folder contains Java implementations of fundamental backtracking concepts along with popular interview problems such as **N-Queens**, **Sudoku Solver**, **Permutations**, and **Subsets**.
