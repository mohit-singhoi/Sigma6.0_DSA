# 📖 Overview

Hashing is one of the most important techniques in Data Structures and Algorithms. It enables **fast insertion, deletion, and searching** by mapping keys to values using a hash function.

This folder contains Java implementations of HashMap, HashSet, LinkedHashMap, LinkedHashSet, TreeMap, TreeSet, and several classic hashing problems frequently asked in coding interviews and competitive programming.
