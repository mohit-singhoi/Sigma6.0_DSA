# 🔀 Conditional Statements

> A collection of **Java Conditional Statement** programs covering decision-making concepts such as **if**, **if-else**, **switch-case**, nested conditions, and basic problem-solving. These programs were implemented as part of the **Sigma 6.0 – Data Structures & Algorithms with Java** course by **Apna College**.

---

# 📖 Overview

Conditional statements are fundamental building blocks in programming that allow a program to make decisions based on specific conditions. This folder contains beginner-friendly Java programs that demonstrate how different conditional constructs work and how they can be applied to solve real-world problems.

These programs helped build a strong foundation in control flow before moving on to advanced Data Structures and Algorithms.
