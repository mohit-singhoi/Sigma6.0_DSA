# 📋 ArrayList

> A comprehensive collection of **Java ArrayList** implementations and interview-oriented problems completed as part of the **Sigma 6.0 DSA with Java** course by **Apna College**.

---

# 📖 Overview

This folder contains Java programs that demonstrate the fundamentals and advanced operations of the **ArrayList** class from the Java Collections Framework. It covers basic CRUD operations, traversals, sorting, multidimensional ArrayLists, and classic interview problems solved using optimized approaches.
