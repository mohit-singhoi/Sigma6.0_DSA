# 📖 Overview

A **Stack** is a linear data structure that follows the **LIFO (Last In, First Out)** principle, where the last element inserted is the first one to be removed. Stacks are widely used in expression evaluation, recursion, compiler design, backtracking, and many algorithmic problems.

This folder contains Java implementations of stack operations, stack manipulation techniques, and several classic interview problems that utilize stacks efficiently.
