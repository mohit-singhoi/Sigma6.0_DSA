# 📖 Overview

Dynamic Programming (DP) is an optimization technique used to solve problems by breaking them into smaller overlapping subproblems and storing their results to avoid redundant computations.

This folder contains Java implementations of beginner to advanced Dynamic Programming problems, including **0/1 Knapsack**, **Longest Common Subsequence (LCS)**, **Longest Increasing Subsequence (LIS)**, **Catalan Numbers**, **Matrix Chain Multiplication (MCM)**, **Wildcard Matching**, and many more.

Each problem is implemented using one or more of the following approaches:

- 🔁 Recursion
- 💾 Memoization (Top-Down DP)
- 📊 Tabulation (Bottom-Up DP)
