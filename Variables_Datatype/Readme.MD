# 📝 Variables & Data Types

> A beginner-friendly collection of **Java programs** covering **variables, data types, arithmetic operations, mathematical calculations, unit conversions, and basic problem-solving**. This folder is part of the **Sigma 6.0 – Data Structures & Algorithms with Java** course by **Apna College**.

---

# 📖 Overview

Variables and Data Types are the foundation of every programming language. They allow us to store, manipulate, and process different kinds of data efficiently.

This folder contains Java programs that introduce the core concepts of variables, primitive data types, arithmetic operations, mathematical formulas, and real-world calculations. These programs build a strong foundation for learning conditional statements, loops, functions, object-oriented programming, and Data Structures & Algorithms.

# 📚 Programs Included

| Program | Description |
|----------|-------------|
| `Average.java` | Calculates the average of numbers |
| `Cost.java` | Calculates the total cost of multiple items |
| `Result.java` | Demonstrates variable declaration and output |
| `Square.java` | Calculates the square of a number |
| `Swap.java` | Swaps two numbers using a third variable |
| `Swap1.java` | Swaps two numbers without using a third variable |
| `CelsiusToFahrenheit.java` | Converts Celsius to Fahrenheit |
| `FahrenheitToCelsius.java` | Converts Fahrenheit to Celsius |

| `CompoundInterest.java` | Calculates Compound Interest |
