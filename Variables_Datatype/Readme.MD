> A beginner-friendly collection of **Java programs** covering **variables, data types, arithmetic operations, input/output, and basic mathematical calculations**. This folder is part of the **Sigma 6.0 – Data Structures & Algorithms with Java** course by **Apna College**.

---

# 📖 Overview

Variables are the foundation of every programming language. They are used to store and manipulate data, while data types define the kind of values a variable can hold.

This folder contains Java programs that introduce the fundamentals of variables, arithmetic operations, expressions, and basic problem-solving. These programs build the foundation required for learning conditional statements, loops, functions, object-oriented programming, and Data Structures & Algorithms.
