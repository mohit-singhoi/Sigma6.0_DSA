# 📖 Overview

Graphs are one of the most powerful and widely used data structures in computer science. They are used to model relationships between objects and solve complex real-world problems involving networks, routing, dependency management, and optimization.

This folder contains Java implementations of graph traversal techniques, shortest path algorithms, minimum spanning trees, connected components, cycle detection, disjoint sets, and many advanced graph algorithms frequently asked in coding interviews and competitive programming.

# 📈 Time Complexities

| Algorithm | Complexity |
|-----------|------------|
| BFS | **O(V + E)** |
| DFS | **O(V + E)** |
| Check Path | **O(V + E)** |
| Connected Components | **O(V + E)** |
| Cycle Detection | **O(V + E)** |
| Bipartite Graph | **O(V + E)** |
| Topological Sort | **O(V + E)** |
| Bellman-Ford | **O(V × E)** |
| Floyd-Warshall | **O(V³)** |
| Prim's Algorithm | **O(E log V)** |
| Kruskal's Algorithm | **O(E log E)** |
| Disjoint Set Operations | **Almost O(1)** |
| Flood Fill | **O(M × N)** |
| Kosaraju's Algorithm | **O(V + E)** |
| Bridge Algorithm | **O(V + E)** |
| Articulation Point | **O(V + E)** |
